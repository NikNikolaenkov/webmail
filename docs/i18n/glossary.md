# Глосарій перекладу (uk)

Спільний для форків `NikNikolaenkov/webmail` і `NikNikolaenkov/webui`. Якщо копії розходяться, головна — у `webui`.

| English | Українською | Примітка |
|---|---|---|
| account | обліковий запис | не «акаунт» |
| mailbox (сховище листів користувача) | скринька | |
| mailbox / folder (IMAP-тека) | тека | «Вхідні», «Надіслані», «Чернетки», «Кошик», «Спам», «Архів» |
| alias | псевдонім | |
| app password | пароль застосунку | |
| domain | домен | |
| identity | ідентичність | адреса відправника з підписом |
| sign in / sign out | увійти / вийти | |
| CC / BCC | копія / прихована копія | |
| Re: / Fwd: | без перекладу | стандартні префікси тем |
| push notifications | push-сповіщення | |
| filter | фільтр | правила Sieve |
| settings | налаштування | |
| OK (кнопка) | Гаразд | |
| JMAP, IMAP, SMTP, CalDAV, CardDAV, WebDAV, Sieve, OAuth, TOTP, S/MIME, PGP | без перекладу | назви протоколів |

Приклади адрес і URL у підказках полів (`user@example.com`, `https://…`) не перекладаються.
